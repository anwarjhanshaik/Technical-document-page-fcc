Introduction To Python

What is python?

Python is a popular programming language. It was created by Guido van Rossum, and released in 1991

Python is a high-level, general-purpose programming language renowned for its readability and simple,English-like syntax, making it an ideal choice for beginners. It is dynamically typed and supports multipleprogramming paradigms, including procedural, object-oriented, and functional programming.

  • web development (server-side),
  • software development,
  • mathematics,
  • system scripting.

What can Python do?

  • Python can be used on a server to create web applications.
  • Python can be used alongside software to create workflows.
  • Python can connect to database systems. It can also read and modify files.
  • Python can be used to handle big data and perform complex mathematics.
  • Python can be used for rapid prototyping, or for production-ready software development.

Python Syntax compared to other programming languages

  • Python was designed for readability, and has some similarities to the English language with influence from mathematics.
  • Python uses new lines to complete a command, as opposed to other programming languages which often use semicolons or parentheses.
  • Python relies on indentation, using whitespace, to define scope; such as the scope of loops, functions and classes. Other programming languages often use curly-brackets for this purpose
What you should already know

You don't need any formal knowledge before learning Python as it is considered one of the most beginner-friendly languages. The key prerequisites are basic computer skills (like file management), a problem-solving mindset, and the willingness to practice consistently.

Essential Skills and Mindset

  • Basic computer literacy: You should be comfortable with using a computer, navigating files, and typing.
  • Problem-solving mindset: Programming is essentially about solving problems. It helps to have a task or problem you want to solve, as this provides motivation and a practical application for what you learn.
  • Patience and persistence: You will encounter errors and get stuck. The ability to be patient, debug (often by using print statements or Google searches), and keep trying is crucial.
  • Logical thinking: Basic mathematical logic (like if/else conditions and loops) is the foundation of programming.
  • Ability to read documentation: While many tutorials exist, learning to read official documentation is a vital skill for long-term success as a programmer.

Variables

In Python, a variable is a symbolic name (or label) that references an object or value stored in memory. Unlike some other programming languages, Python is dynamically typed, meaning you do not need to explicitly declare a variable's data type, and the type can change during execution.

Key Concepts

  • Assignment: Variables are created using the assignment operator (=). The variable name goes on the left, and the value to be stored (the object) goes on the right.
    # Example assignments
age = 25              
# age is an 
integer variable
name = "Alice"        
# name is a 
string variable
is_student = True     
# is_student is 
a boolean variable
  • Dynamic Typing: Python automatically determines the data type of the variable based on the assigned value. A variable can be reassigned a value of a different type:
    x = 10     
# x is an int
x = "hello"
# x is now a string
  • Object References: Variables don't directly store values; they are references (pointers) to objects in memory. When you assign y = x, both y and x point to the same object.
Variable Scope

The scope of a variable determines where in the program it can be accessed.

  • Local Scope: Variables defined inside a function are local to that function and can only be used within it.
  • Global Scope: Variables defined in the main body of the script are global and can be accessed throughout the program, including inside functions.
  • The global keyword can be used to modify a global variable from within a function.
Data Types

In Python, data types categorize the kind of value a variable holds, which determines what operations can be performed on it. Because everything in Python is an object, these data types are actually classes, and variables are instances of these classes.

Think of Python data types like different kinds of containers used to store information. Depending on what you want to save, you pick the right "box":

  • Numeric Types: Used to store numerical values.
    • int: Integers (whole numbers, positive or negative) with unlimited length.
    • float: Floating-point numbers (numbers with a decimal point).
    • complex: Complex numbers, written as a real part and an imaginary part with a j suffix (e.g., 2 + 3j).
  • Sequence Types: Ordered collections of items, supporting indexing and slicing.
    • str: Strings, used for text and sequences of characters, enclosed in single, double, or triple quotes.
    • list: Mutable (changeable) collections of items, which can be of different data types, created using square brackets [].
    • tuple: Immutable (unchangeable) collections of items, created using parentheses ().
    • range: Represents an immutable sequence of numbers, often used in loops.
  • Mapping Type:
    • dict: Dictionaries are ordered3.7+ collections of data in key-value pairs, created using curly braces {}. Keys must be unique and immutable.
  • Set Types: Unordered collections of unique items, defined using curly braces {} or the set() function.
    • set: Mutable sets.
    • frozenset: Immutable sets.
  • Boolean Type:
    • bool: Represents logical values, which can be either True or False. Boolean objects are a subtype of integers, where True is equivalent to 1 and False is equivalent to 0.
  • None Type:
    • Nonetype: Represents the absence of a value or a null value. It has only one value: None.
  • Binary Types:
    • bytes: Immutable sequences of bytes.
    • bytearray: Mutable sequences of bytes.
    • memoryview: Provides a view into the memory of other binary objects without copying the data.
If/Else Statements in Python

The if...else statements in Python are conditional statements that allow a program to make decisions and execute different blocks of code based on whether a specified condition is true or false. This control flow mechanism is fundamental to programming logic.

Types of If...Else Statements

Python offers several ways to handle conditional logic:

  • if statement: Executes a block of code only if the condition is True.
  • if...else statement: Executes the if block if the condition is True, and the else block if the condition is False.
  • if...elif...else ladder: Checks multiple conditions sequentially, executing the first block whose condition is True. If no condition is met, the final else block is executed.
  • Nested if statements:
  • Syntax:
    if condition1:
  #Code to execute if
  condition1 is True
elif condition2:
  #Code to execute if
  condition2 is True
  #Can have more 
  elif blocks
else:
  #Code to execute if
  none of the above
Loops

In Python, loops are used to automate repetitive tasks by executing a block of code multiple times. Python primarily uses two types of loops: for and while.

  1. The for Loop

    The for loop is used for sequential traversal, meaning it iterates over a pre-defined sequence like a list, string, tuple, or range. It is best used when you know exactly how many times you want to repeat a task.

    • Common Use Case: Iterating through all items in a list or characters in a string.
    • Key Function: The range() function is often used with for loops to generate a sequence of numbers (e.g., range(5) generates 0 to 4)
  2. The while Loop:

    The while loop repeats a block of code as long as a specific condition remains true. It is ideal when you don't know the exact number of iterations beforehand, such as waiting for a specific user input.

    • Infinite Loops: If the condition never becomes false, the loop will run forever unless stopped manually (e.g., while True:).
Function declarations

In Python, a function declaration (often called a "definition") is like writing a recipe. You define the steps once, give it a name, and then you can "cook" that recipe whenever you want without rewrite the instructions.

  1. The Basic Anatomy

    You use the def keyword to tell Python you are making a function.

    def greet_user():
  print("Hello there!")
    • def: Short for "define." It starts the declaration.
    • greet_user: This is the name. You choose it (use lowercase and underscores).
    • (): The parentheses are for "ingredients" (parameters). Even if you don't have any, you still need the brackets.
    • :: The colon says, "Here comes the list of instructions."
    • Indentation: Everything inside the function must be indented (pushed to the right).
